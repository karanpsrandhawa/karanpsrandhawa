### 🔭 Featured project

**[sports-odds-modelling](https://github.com/karanpsrandhawa/sports-odds-modelling)**:
a Python pipeline that pulls live odds from The Odds API and turns bookmaker prices into fair probabilities by removing the margin with the Shin and power methods.
It builds a cross-market consensus and flags quotes that look mispriced against it.
A Claude API stage then sorts the flagged quotes into likely real discrepancies and likely data artefacts.
Includes calibration metrics (Brier score, log loss, ECE), and pytest runs on GitHub Actions.
